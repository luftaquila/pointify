# pointify-firmware

CH32X033F8P6 firmware. Built on [ch32-hal](https://github.com/ch32-rs/ch32-hal) with [Embassy](https://embassy.dev/) async runtime.

## Prerequisites

```bash
cargo install probe-rs-tools
```

## Build & flash

```bash
cargo run --release
```

Build only:

```bash
cargo build --release
```
